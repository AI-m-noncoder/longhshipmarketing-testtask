# Longship Marketing – n8n Technical Exercise

**Task 3: Campaign Metrics  Insight Summary Stored in PostgreSQL**

## Contents

- `campaigns.csv` — sample campaign data (CSV data source)
- `workflow_task3.json` — n8n workflow export
- `task3_longship.md` — full write-up with design decisions and setup notes

## Quick start

1. Import `workflow_task3.json` into n8n
2. Set up credentials:
   - Airtable (Personal Access Token)
   - OpenRouter (API key)
   - PostgreSQL (tested on Supabase)
3. Run the SQL schema from the write-up to create tables
4. Click the trigger to run

See `task3_longship.md` for full details.
